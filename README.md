# RunwayML OpenAPI spec

This repository contains an [OpenAPI](https://spec.openapis.org/oas/v3.1.0.html) specification for the [RunwayML API](https://docs.dev.runwayml.com).

It is generated with [Stainless](https://www.stainless.com/).

## Spec

> [!CAUTION]
> This spec is primarily intended for RunwayML's internal use. Stability of the spec is not guaranteed.

[**View the spec**](openapi.yml)

- [sdk-python](https://github.com/runwayml/sdk-python) (Python)
